Signal Pipeline

How NEXUS sees the room

Every WiFi packet crossing a room carries a fingerprint of the space it traversed. NEXUS reads that fingerprint and translates its changes into presence and motion.

01

Packet Capture

The ESP32 promiscuously captures passing 802.11 frames and extracts their Channel State Information (CSI) payload.

02

Amplitude Extraction

Magnitude is computed across all subcarrier amplitudes. A heartbeat of pings ensures packet rate stays high enough.

03

Baseline Learning

Builds a running average of the empty-room signature. Freezes immediately when motion is detected.

04

State Classification

Deviation from baseline is bucketed into four states: Idle, Presence, Motion, High Motion.

Capabilities

Everything included, nothing extraneous

Privacy First

No camera, no microphone, no image ever captured. Presence inferred from radio energy only.

Live Web Dashboard

Dark cybersecurity-styled UI served from the device. WebSocket updates, activity charts, CSV export.

Adaptive Baseline

Learns your room on startup. Adapts slowly to drift. Freezes learning instantly when motion is detected.

4-Level Detection

Idle → Presence → Motion → High Motion, each with independently tunable thresholds.

OTA Firmware Updates

Flash new firmware from the dashboard. Verified before boot, with automatic rollback on failure.

AP Fallback

Can't reach WiFi? Device hosts its own NEXUS-CSI-Setup network so you're never locked out.

Optional Display

1.8" ST7735 color screen for on-device status: state, motion score, signal quality, IP address.

Self-Healing

FreeRTOS watchdog reboots automatically if any task stalls. Designed for months of unattended operation.

Get Running

Three steps to a live sensor

You need an ESP32 and a USB data cable. That's the real minimum.

1

Flash the firmware

Download the prebuilt binary from the latest release, or build from source with ESP-IDF v5.x. Full instructions in docs/FLASHING.md.

$ esptool.py --port /dev/ttyUSB0 --baud 460800 write_flash 0x0 nexus-csi-v1.0.0.bin
2

Connect to your WiFi

On first boot the device hosts NEXUS-CSI-Setup. Join it from your phone and enter your WiFi credentials. See docs/USAGE.md.

3

Dashboard & calibrate

Navigate to the device IP, log in, change the default password, and run room calibration. See docs/CALIBRATION.md.
